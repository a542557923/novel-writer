# Novel Writer ✒

轻量化的 AI 小说写作工具。提示词编排参考 SillyTavern，核心差异化：**世界书随写作自动生长**——写作中途新出现的人物、物品、地点会被自动提取入库，后续章节自动注入，AI 不会"忘记"配角和道具。

## 核心特性

- **世界书自动记忆循环**：每段生成完成后，自动从新正文中抽取实体（人物/物品/地点/组织/设定）入库；已有实体的重大新信息（受伤、身份揭示、获得物品…）自动追加更新
- **分层记忆（滚动摘要）**：每章自动生成剧情摘要（保留伏笔与人物状态）；生成时按「前情摘要 + 近 N 章原文 + 当前章」分层装配上下文，长篇不再"顾此失彼"；摘要累积到阈值自动折叠为卷摘要，原文永久保留
- **ST 式提示词组装**：System → 前置设定 → 本书大纲 → 常驻角色 → 触发设定 → 前情摘要 → 近章原文 → 当前章（作者注按深度插入）→ 本次指令
- **关键词触发注入**：非重要条目不占上下文，仅在最近剧情提及时注入；英文触发词带词边界匹配，避免误命中
- **注入预览 + 发送历史**：生成前预览组装结果；生成后可查看每次**实际发送**给模型的完整消息、上下文分层构成（摘要/近章/当前章各占多少字）与压缩情况
- **四种写作模式**：续写 / 扩写选中 / 润色选中 / 自定义指令，均支持流式输出与中途停止
- **选中一键入库**：选中正文中任意一段文字，点击按钮即可加入世界书
- **公益站友好**：每次生成最多 2 次请求（1 次正文生成 + 1 次后台整理），全部串行、固定间隔、无并发；正文生成期间后台任务主动让路。提供「省流模式」：关闭全部后台任务，严格 1 次请求
- **极轻量**：后端仅依赖 express，数据存本地 JSON 文件，无需数据库

## 请求模型（公益站友好说明）

本工具**不是 agent 型工具**，不会产生循环式的密集请求：

| 动作 | 请求数 | 类型 |
|---|---|---|
| 点击一次生成 | 1 次（流式正文） | 你等待 |
| 生成完成后（自动） | 1 次（世界书抽取 + 章节摘要合并调用） | 后台，延迟数秒执行 |
| 每 10 章 | 1 次（折叠卷摘要，摊薄） | 后台 |
| 记忆面板手动补建 | 每章 1 次 | 后台串行队列 |

- 所有后台任务**全局串行**，两次调用之间保持最小间隔（约 3 秒）
- 你正在生成正文时，后台任务自动让路，不会并发请求
- 开启「省流模式」后，每次生成**严格只有 1 次请求**（无自动整理；摘要可在「记忆」面板手动补建）

## 快速开始

要求 Node.js ≥ 18。

```bash
# 1. 安装依赖
npm install

# 2. 构建前端（一次性）
npm run build

# 3. 启动服务（每次使用前执行，窗口保持开启）
npm start
```

浏览器打开 http://localhost:3210 即可使用。

启动后在右侧「设置」面板填写：

| 配置项 | 说明 |
|---|---|
| API 地址 | 任意 OpenAI 兼容接口，填到 `/v1`，如 `https://api.deepseek.com/v1` |
| API Key | 你的密钥 |
| 模型 | 如 `deepseek-chat`、`gpt-4o` 等 |
| 抽取模型 | 可选。额度充裕时留空即可（复用主模型，抽取与摘要共用）；使用推理模型写作或额度受限时，建议单独指定一个快速小模型 |

## 数据存储

所有数据保存在项目目录的 `data/` 文件夹：

```
data/
├── config.json        # 全局 AI 配置（含 API Key，不要分享这个文件！）
├── requests/          # 发送记录（每次实际发给模型的消息，可随时删除）
└── projects/          # 每部作品一个 JSON 文件
    └── <id>.json      # 设定 + 章节 + 世界书 + 分层记忆（摘要/卷摘要）
```

备份 `data/` 文件夹 = 备份全部作品。

## 使用建议

1. 新建作品后，先在「设置 → 本书写作设置」填写大纲与核心世界观（每次生成都注入）
2. 主要角色、力量体系等关键设定，建世界书条目时勾选「常驻注入」（等价于 SillyTavern 的角色卡）
3. 保持「生成后自动整理」开启，写几章后世界书会自己积累出一部设定集，记忆面板会积累出全书摘要
4. 定期在「注入预览 → 发送历史」检查实际发给模型的内容与压缩构成，据此调整上下文预算与近章数
5. 已有大量章节后再开始用的话，到「记忆」面板点「补齐缺失摘要」，让旧章节一次性补上记忆
