# Novel Writer ✒

轻量化的 AI 小说写作工具。提示词编排参考 SillyTavern，核心差异化：**世界书随写作自动生长**——写作中途新出现的人物、物品、地点会被自动提取入库，后续章节自动注入，AI 不会"忘记"配角和道具。

## 核心特性

- **世界书自动记忆循环**：每段生成完成后，自动从新正文中抽取实体（人物/物品/地点/组织/设定）入库；已有实体的重大新信息（受伤、身份揭示、获得物品…）自动追加更新
- **ST 式提示词组装**：System → 前置设定 → 本书大纲 → 常驻角色 → 触发设定 → 正文上下文（作者注按深度插入）→ 本次指令
- **关键词触发注入**：非重要条目不占上下文，仅在最近剧情提及时注入；英文触发词带词边界匹配，避免误命中
- **注入预览**：每次生成前可查看实际发送给模型的完整提示词、被注入的条目及来源（常驻/触发/前置）
- **四种写作模式**：续写 / 扩写选中 / 润色选中 / 自定义指令，均支持流式输出与中途停止
- **选中一键入库**：选中正文中任意一段文字，点击按钮即可加入世界书
- **极轻量**：后端仅依赖 express，数据存本地 JSON 文件，无需数据库

## 快速开始

要求 Node.js ≥ 18。

```bash
# 1. 安装依赖
npm install

# 2. 构建前端（一次性）
npm run build

# 3. 启动服务（每次使用前执行，窗口保持开启）
npm start
```

浏览器打开 http://localhost:3210 即可使用。

启动后在右侧「设置」面板填写：

| 配置项 | 说明 |
|---|---|
| API 地址 | 任意 OpenAI 兼容接口，填到 `/v1`，如 `https://api.deepseek.com/v1` |
| API Key | 你的密钥 |
| 模型 | 如 `deepseek-chat`、`gpt-4o` 等 |
| 抽取模型 | 可选，建议填一个便宜快速的小模型专门做实体抽取，留空则用主模型 |

## 数据存储

所有数据保存在项目目录的 `data/` 文件夹：

```
data/
├── config.json        # 全局 AI 配置（含 API Key，不要分享这个文件！）
└── projects/          # 每部作品一个 JSON 文件
    └── <id>.json      # 设定 + 章节 + 世界书
```

备份 `data/` 文件夹 = 备份全部作品。

## 使用建议

1. 新建作品后，先在「设置 → 本书写作设置」填写大纲与核心世界观（每次生成都注入）
2. 主要角色、力量体系等关键设定，建世界书条目时勾选「常驻注入」（等价于 SillyTavern 的角色卡）
3. 保持「生成后自动抽取」开启，写几章后世界书会自己积累出一部设定集
4. 定期在「注入预览」检查实际发给模型的内容，据此调整上下文预算与扫描窗口
